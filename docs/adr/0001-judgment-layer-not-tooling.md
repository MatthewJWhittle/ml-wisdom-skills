# Own the judgment layer; compose with tool skills

Public ML Agent Skills are already dense on Hub/CLI/trainer workflows (Hugging Face Skills, Ultralytics, TAO, much of K-Dense). We decided this repo’s job is framework-agnostic researcher judgment — gates, diagnostics, experiment discipline, and objective loops — not another encyclopedia of how to call tools. Thin scripts are allowed only when they support that judgment and stay portable across repos. We compose with existing tool skills instead of competing with them.
