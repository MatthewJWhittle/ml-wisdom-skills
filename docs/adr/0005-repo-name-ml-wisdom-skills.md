# Public repo name: ml-wisdom-skills

We chose `ml-wisdom-skills` as the public GitHub repo name. It is free of exact collisions, signals researcher judgment rather than Hub/tool how-tos, and avoids crowded names (`ml-skills`, `ml-research-skills`, `karpathy-skills`). Spine skill directories are verb-named (`wire-feedback`, `verify-training`, …); CV overlays stay `cv-*`. The repo name carries the brand.
