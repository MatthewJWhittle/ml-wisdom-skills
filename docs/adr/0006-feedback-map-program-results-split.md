# Split durable wiring from loop contracts; scope the mutable surface

Consumer repos get `AGENTS-FEEDBACK.md` as a standing feedback/wiring guide (and a durable try log of what was attempted across work). An objective-loop run adds `program.md` (goal, method, keep rules, allowed mutable surface) plus `results.tsv` and a reasoning-trace channel. If MLflow (or similar) already exists, the loop registers against it rather than replacing it. Before iterating on code, the agent must establish scope (what may change) and safety defaults (branch, no deleting data, no touching untracked datasets, ask before destructive steps).
